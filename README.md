# OmniScribe

Веб-сервис для заметок с живыми связями и визуальной эстетикой.

> ⚠️ **Статус:** Ранний прототип. Проект в активной разработке.

## 💭 Идея

Я делаю OmniScribe, потому что красивое и полезное, и есть такое желание. Это попытка создать пространство для мыслей, где:

- 🔗 **Заметки связаны графами** — видны отношения между идеями
- 🌫️ **Заметки "стареют"** — если ты долго не открываешь заметку, она плавно становится серой/полупрозрачной, помогая фокусироваться на актуальном
- 🎨 **Интерфейс кастомизируется** — гибкая система тем, потому что визуальная среда влияет на мышление
- 🧩 **Интерактивные элементы** — в будущем: временные шкалы, аудиоплееры, ноды для таблиц

## 🛠 Текущий статус

**Что уже работает:**
- ✅ CRUD заметок (создание, редактирование, удаление)
- ✅ Markdown-форматирование
- ✅ Гибкая система тем с кастомизацией цветов
- ✅ Базовая структура фронтенда и бэкенда

**В разработке:**
- 🚧 Визуализация графа связей между заметками
- 🚧 Эффект "увядания" неиспользуемых заметок
- 🚧 Сервис модальных окон
- 🚧 Интерактивные элементы (папки, таймлайны, плееры)

## 🏗 Стек технологий

- **Frontend:** Svelte
- **Backend:** Python
- **Database:** PostgreSQL
